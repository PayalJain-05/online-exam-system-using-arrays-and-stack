# online-exam-system-using-arrays-and-stack
The Online Examination System is a basic exam management system developed using Data Structures in Python. It allows users to attempt multiple-choice questions, submit answers, review their attempts, and receive their final score.

The project demonstrates the practical use of arrays and stacks:

Arrays are used to store questions, options, correct answers, and student responses.

Stacks are used to maintain the order of attempted questions and support answer review/navigation.

The system evaluates the submitted answers and generates the final examination result.

Person 4 – Answer Evaluation & Result Generation

My contribution focused on the answer evaluation and result generation module. I worked on comparing the student's selected answers with the correct answers stored in the system, calculating the total score, and displaying the final result. I also worked with the stack-based question sequence to support the review of attempted questions.

This project helped demonstrate how arrays and stacks can be applied to build a simple real-world examination system.
